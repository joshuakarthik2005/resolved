The problem

A shop owner's UPI payment fails.

They message support. It sits in a queue for days, while RBI gives the bank until T+5 to put it right, and ₹100 a day is owed after that.

Resolved.

How we solve it

The model proposes. Code decides.

An LLM reads the message and proposes exactly one action.

A separate gate with no model in it runs five deterministic checks and rules approve, escalate or block.

The model never moves money.
